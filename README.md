# Multi-Chat App

A **modern, real-time multi-chat web application** with support for group chats, direct messaging, media sharing, and more. Built with **React**, **Node.js**, **Socket.IO**, and **MongoDB**, designed for scalability and modern web experiences.  

---

## **Features**

- **Real-Time Messaging:** Instant messages powered by Socket.IO.  
- **Multi-Chat Support:** Join multiple chat rooms or send direct messages.  
- **User Authentication:** Secure login and registration using JWT.  
- **Profiles & Avatars:** Customize profile and display pictures.  
- **Typing Indicators & Online Status:** See who is typing or online.  
- **Media Sharing:** Share images and files in chats.  
- **Search & History:** Retrieve past messages easily.  
- **Responsive Design:** Mobile-friendly and desktop-ready.  
- **Docker-Ready:** Frontend, backend, and database run in containers for easy deployment.  

---

## **Tech Stack**

- **Frontend:** React.js, TailwindCSS / Material UI  
- **Backend:** Node.js, Express.js, Socket.IO  
- **Database:** MongoDB / MongoDB Atlas  
- **Real-Time Communication:** Socket.IO  
- **Containerization:** Docker & Docker Compose
